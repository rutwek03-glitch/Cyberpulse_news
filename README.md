# CyberPulse — Daily Cybersecurity Brief

A responsive static website for GitHub Pages, dated October 16, 2026. It includes news cards, official source links, a student case study, and a response form.

## Deploy on GitHub Pages
1. Create a GitHub repository (for example, `cyberpulse-news`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the page.

## Student response form and central spreadsheet
The response section embeds the CyberPulse Google Form. To collect responses in one central spreadsheet, open the form in Google Forms → **Responses** → click the green Google Sheets icon → create or select a spreadsheet. Submissions are recorded centrally once the form is published/accepting responses and the sheet is linked. Test one sample submission and confirm it appears in the sheet before sharing the site.

Do not collect passwords, sensitive personal information, or confidential organizational data in the form.

## News sources
The page links to CERT-In advisories and supporting reporting. Recheck source pages and update the stories before republishing because news can change.
